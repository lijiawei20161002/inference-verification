## Honest frozen-token replay

Generation used the first 80 built-in prompts, capped at 32 prompt tokens, BF16,
eager sequential generation, temperature 1, top-k 50, top-p 0.95, and shared seed
42. Injected logit and activation noise were disabled. Replay consumed the saved
prompt and output token IDs without retokenizing or generating another output.

The baseline is batch-1 eager full-sequence replay. Positive d′ means the alternate
schedule raises scores. Values use baseline 99.9th-percentile winsorization and
baseline standard deviation. Intervals are exploratory **90% paired sequence
bootstrap intervals**, with 400 draws and seed 0; token positions are not independent
bootstrap units. They are not simultaneous bounds.

| Replay schedule | Detector | d′ | 90% paired interval |
|---|---|---:|---|
| chunked_b4 | token_difr | +0.000000 | [+0.000000, +0.000000] |
| chunked_b4 | cross_entropy | +0.000000 | [+0.000000, +0.000000] |
| chunked_b4 | token_toploc | +0.000000 | [+0.000000, +0.000000] |
| chunked_b4 | activation_difr | +0.000000 | [+0.000000, +0.000000] |
| chunked_b1_sdpa | token_difr | +0.011843 | [-0.000022, +0.023316] |
| chunked_b1_sdpa | cross_entropy | -0.000091 | [-0.000590, +0.000422] |
| chunked_b1_sdpa | token_toploc | +0.009021 | [-0.000979, +0.018261] |
| chunked_b1_sdpa | activation_difr | -0.055683 | [-0.073195, -0.043078] |
| sequential | token_difr | -0.028135 | [-0.037508, -0.018211] |
| sequential | cross_entropy | -0.001775 | [-0.002372, -0.001192] |
| sequential | token_toploc | -0.023487 | [-0.031324, -0.014861] |
| sequential | activation_difr | -1.617968 | [-1.897522, -1.377880] |

`activation_difr` requires internal projected activations and is an additional
visibility control. The other three detectors use returned tokens and reference
recomputation; `token_difr` additionally requires the shared RNG contract. The
saved `frac_tokens_changed` statistic counts changed **scores**, while returned
token IDs are held fixed. These results quantify honest schedule changes; they
are not measurements of model substitution or real quantized-weight detection.

All twelve effect sizes, confidence intervals, and other saved aggregate statistics exactly match the 16 October H100 artifact. This is an aggregate replication on another H100 host/driver; the old run has no frozen capture or per-position scores with which to establish row-by-row equality.
